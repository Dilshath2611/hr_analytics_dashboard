# HR Analytics Dashboard | Power BI

## Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI to explore employee data, understand attrition patterns, and analyze workforce distribution and job satisfaction.

## Tools Used

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and KPIs

## Key Performance Indicators

- **Overall Employees:** 446
- **Attrition:** 92 employees
- **Attrition Rate:** 20.63%
- **Active Employees:** 354
- **Average Employee Age:** 37

## Dashboard Features

- Department-wise attrition analysis
- Employee distribution across age groups and gender
- Job satisfaction ratings by job role
- Education-field-wise attrition
- Attrition-rate analysis across different age groups

## Key Insights

- The dashboard reports an overall attrition rate of 20.63%.
- R&D has the highest attrition count among the departments displayed.
- Sales Executives represent the largest job-role group in the job satisfaction table.
- The dashboard helps explore workforce patterns across age groups, gender, and education fields.
